1. 에이전트와 스킬

가. 챗봇과 에이전트

챗봇은 대화창 안에서 질문을 받고 답을 만들어 줌. 에이전트는 지정한 폴더의 파일을 직접 읽고 쓰며, 프로그램과 브라우저를 조작해 맡긴 일을 끝까지 수행함.

나. 스킬

스킬은 특정 업무의 절차와 조작 요령을 적어 둔 폴더임. 폴더의 핵심 파일은 SKILL.md이고, 에이전트는 이 파일에 적힌 단계에 따라 작업함.

늘 지켜야 할 규칙은 규칙 파일(Claude는 CLAUDE.md, Codex는 AGENTS.md)에 적고, 특정 업무의 절차는 스킬에 담음.

다. 에이전트가 스킬을 고르는 방식

SKILL.md의 첫머리에는 두 줄의 --- 사이에 스킬 정보가 적혀 있음. 스킬 이름인 name과, 이 스킬을 언제 쓰는지 설명하는 description이 들어 있음.

  • 평소: 에이전트는 스킬 본문을 읽지 않고 첫머리의 name과 description만 알고 있음.
  • 요청이 맞을 때: 사용자의 요청이 description과 맞으면 그 스킬의 SKILL.md 본문을 읽음.
  • 참고 파일: 본문이 가리키는 참고 파일은 해당 업무를 할 때만 읽음. 스킬을 많이 설치해도 필요한 파일만 읽힘.
  • 사용 방법: 스킬은 켜고 끄는 것이 아님. 설치 후 새 대화에서 할 일을 입력하면 에이전트가 맞는 스킬을 고름. 스킬 이름을 지시문에 직접 넣어도 됨.

Codex와 Claude는 같은 형식의 SKILL.md를 읽음. 차이점은 스킬이 저장되는 폴더뿐임.

2. 따라 하기 1: 스킬 설치하기

가. school-work-automation 번들

school-work-automation은 교육행정 시스템 업무의 절차를 모은 무료 오픈소스 스킬 번들임(MIT 라이선스). 스킬 파일에는 사용료가 없고, 에이전트 사용료는 별도임.

저장소 주소는 https://github.com/Engccer/school-work-automation임. 한 저장소에 스킬 네 개가 들어 있어 번들을 설치하면 넷이 함께 들어옴. 스킬끼리 독립적이라 필요 없는 스킬 폴더는 지워도 됨.

스킬 담당 영역
neis-automation 나이스 복무(근무상황·출장 신청), 외부강의 신고, 정기고사 채점·통계, 학생부 화면 입력, 급여명세서, 교육제증명
k-edufine-automation K-에듀파인 결재대기 공문 처리, 공문 본문·첨부 저장, 기안 작성
kyodetong-submit 교데통 데이터취합 접수·첨부·제출
coolmessenger-automation 쿨메신저 회신 수합, 첨부 일괄 수집, 회신 창 채우기

이 번들은 서울시교육청 환경에서 검증했음. 나이스·K-에듀파인·교데통은 전국 공통 시스템이라 시도별 접속 주소와 세부 화면만 다르고 절차의 골격은 같음. 다른 시도에서는 접속할 업무포털 주소를 에이전트에게 알려 주고 화면 차이를 확인하며 진행해야 함.

나. 스킬 저장 위치

이 컴퓨터 전체에서 쓰는 전역 스킬은 홈 디렉터리(C:\Users\<본인 계정 이름>) 아래에 저장됨.

에이전트 전역 스킬 위치
Claude 홈 디렉터리의 .claude\skills
Codex 홈 디렉터리의 .agents\skills

다른 에이전트로 설치했더라도 저장 위치가 맞으면 쓸 수 있음. 설치를 수행한 에이전트보다 저장 위치가 중요함.

다. 설치 절차

1) 설치 요청하기: 에이전트 입력창에 다음 지시문을 입력함.

https://github.com/Engccer/school-work-automation 스킬 번들을 이 컴퓨터 전역에 설치해 줘.

2) 실행 허용하기: 에이전트가 명령 실행 승인을 요청하면 내용을 읽고 허용함. 설치 명령은 npx skills add Engccer/school-work-automation -g이며, npx는 Node.js에 포함돼 있음.

3) 새 대화 열기: 설치가 끝나면 새 대화를 시작함.

4) 설치 결과 확인하기: 새 대화에서 다음 지시문을 입력함.

설치된 스킬이 무엇이고 각각 어느 폴더에 있는지 알려 줘.

5) 네 스킬 확인하기: 응답에 neis-automation, k-edufine-automation, kyodetong-submit, coolmessenger-automation이 모두 있는지 확인함. 응답에 나온 폴더 위치는 따라 하기 2에서 씀.

  • 갱신: 공개 스킬이 개선돼도 설치한 스킬은 자동으로 바뀌지 않음. 최신 내용을 반영하려면 에이전트에게 재설치를 요청해야 함.
  • 출처 확인: 스킬에 적힌 내용이 곧 에이전트가 할 일임. 출처를 모르는 스킬은 설치하지 않고, 설치 전에 저장소의 SKILL.md를 읽어 무엇을 시키는지 확인해야 함.

3. 따라 하기 2: 스킬 폴더 살펴보기

가. 폴더 열기

1) 주소 표시줄로 이동하기: 파일 탐색기에서 Alt+D를 누름. 이름이 점으로 시작하는 폴더는 목록에서 보이지 않을 수 있어 주소를 직접 입력하는 편이 확실함.

2) 스킬 폴더 주소 입력하기: 사용하는 에이전트에 맞는 주소를 입력하고 Enter를 누름.

  • Claude: %USERPROFILE%\.claude\skills\neis-automation
  • Codex: %USERPROFILE%\.agents\skills\neis-automation

3) 하위 항목 읽기: 목록에 SKILL.md, references 폴더, scripts 폴더가 있는지 확인함.

4) SKILL.md 열기: SKILL.md에서 Shift+F10이나 메뉴 키를 눌러 연결 프로그램에서 메모장을 고름. .md 파일은 텍스트 파일이라 메모장에서 센스리더로 읽을 수 있음.

5) 첫머리 읽기: 맨 위 두 줄의 --- 사이에서 name과 description을 찾아 읽음.

6) 참고 파일 찾기: references 폴더로 들어가 근무상황-신청.md를 찾아 같은 방법으로 엶.

나. 폴더의 구성

  • SKILL.md: 스킬의 본체임. 첫머리에 name: neis-automation, 나이스 복무·결재·성적·학생부·급여명세서·교육제증명 등에 쓴다는 description, 버전 정보가 있음. 본문에는 학교 밖 접속(EVPN), 브라우저 연결 사전 점검, 업무포털 접속과 로그인 대기 등 공통 절차가 있음.
  • references 폴더: 업무별 참고 파일임. 근무상황-신청.md, 출장-신청.md, 상신-공통.md, 외부강의-신고.md, 급여명세서.md, 인증서-로그인.md, EVPN.md, 겪은 사례를 기록한 cases.md 등 20개 남짓이 있음.
  • scripts 폴더: 반복 계산과 변환에 쓰는 프로그램임. neis-automation에는 급여명세서를 표로 바꾸는 payslip_csv.py 하나가 있음.

다. 스킬에 쌓인 우회 지식

근무상황-신청.md에는 나이스 복무 화면을 다루는 요령이 단계별로 적혀 있음.

  • 드롭다운: 목록으로 인식되지 않는 커스텀 형식이라 클릭으로만 값을 고를 수 있음.
  • 날짜: 달력 아이콘으로만 입력됨.
  • 시작일과 종료일: 시작일을 바꾸면 종료일이 같은 날로 따라 바뀜.

화면을 손으로 다루면 이런 우회를 매번 다시 찾아야 함. 스킬에는 그 요령이 화면별로 기록돼 있어 에이전트가 같은 시행착오를 반복하지 않음.

라. 스킬 고쳐 쓰기

한 번 받은 스킬은 사용자의 파일이라 고쳐 써도 됨. 다만 원래 이름 그대로 고치면 재설치할 때 수정 내용이 덮어써질 수 있음.

  • 이름 바꾸기: 폴더를 복사한 뒤 폴더 이름과 SKILL.md의 name을 함께 바꿔 별도 스킬로 보관함.
  • 설명 고치기: description도 용도에 맞게 고침. 에이전트는 이 설명을 읽고 스킬을 고름. 예를 들어 울산 업무포털 주소를 적어 둔 복사본을 만들 수 있음.

4. 따라 하기 3: 나이스 복무 신청하기

가. 브라우저 연결

나이스는 외부 프로그램이 데이터를 주고받을 통로(API)를 열어 두지 않았음. 그래서 에이전트는 사람처럼 크롬에서 메뉴를 누르고, 화면을 읽고, 값을 채움.

  • Claude: Claude in Chrome 확장을 설치하고 확장에서 앱과 같은 계정으로 로그인해야 함.
  • Codex: ChatGPT 앱의 설정 > Computer Use에서 크롬 옆의 설치를 눌러 ChatGPT 확장을 설치하고 로그인해야 함.
  • 로그인 확인: 확장이 켜져 있다는 것과 로그인돼 있다는 것은 다름. 에이전트가 확장을 설치하라는 말을 되풀이하면 확장 로그인부터 확인함.
  • 학교 밖 접속: EVPN을 먼저 연결해야 업무포털에 접속됨.

나. 신청 절차

1) 브라우저 연결 확인하기: 에이전트 입력창에 다음 지시문을 입력함. 응답한 탭 제목이 실제로 열어 둔 탭과 같으면 연결된 것임.

지금 크롬에 열려 있는 탭의 제목을 읽어 줘.

2) 업무포털 로그인하기: 에이전트가 연 크롬 탭에서 본인이 쓰는 업무포털에 들어가 인증서로 직접 로그인함. 다른 탭에서 한 로그인은 공유되지 않을 수 있음.

3) 신청 화면 채우기 요청하기: 대괄호를 실제 신청할 값으로 바꿔 입력함.

나이스 개인근무상황관리에서 [날짜] [복무 종류]를 [시작 시각]부터 [종료 시각]까지 신청하는 화면을 채워 줘. 사유는 [사유], 연락처는 [연락처]로 넣어 줘. 승인요청은 누르지 말고 멈춰.

4) 입력값 확인하기: 에이전트가 멈추면 다음 지시문을 입력함. 복무 종류·날짜·시간·사유·연락처가 신청하려는 값과 같은지 확인함.

지금 화면에 채워진 값을 항목별로 다 읽어 줘.

5) 승인요청하기: 값이 맞으면 다음 지시문을 입력함. [승인요청]을 누르면 기안문서상신 화면으로 넘어감.

입력값을 확인했어. 승인요청을 눌러 줘. 기안문서상신 화면이 열리면 결재선과 기안내용을 읽어 주고, 상신은 누르지 말고 멈춰.

6) 결재선 확인하기: 에이전트가 읽어 준 결재선과 기안내용을 확인한 뒤 상신 여부를 본인이 결정함. 상신하면 지정한 결재선으로 신청이 전달됨.

에이전트는 다음 순서로 화면을 채움. 응답을 읽으며 각 단계가 맞게 처리됐는지 확인함.

  • 메뉴: 기본 메뉴 > 복무 > 개인근무상황관리에서 [신청]을 눌러 근무상황신청 대화상자를 엶. 행이 비어 있으면 [행추가]를 눌러 입력할 행을 만듦.
  • 근무상황 분류: 대분류(연가·병가·공가·특별휴가 등)를 고른 뒤 소분류까지 선택해야 함. 조퇴·외출·지각·반일연가는 연가 아래에, 육아시간은 특별휴가 아래에 있음. 연가 계열은 연가 잔여일수에서 차감되므로 사용현황 표의 잔여일수를 함께 확인함.
  • 날짜와 시간: 시작일을 먼저 정함. 하루 신청은 시작일과 종료일을 같은 날로 두고 시각만 바꾸며, 신청시간이 0일 N시간 0분으로 계산됐는지 확인함. 여러 날 같은 시간대는 [일반복]을 체크해 N일 매 0시간 N분 형식으로 계산됐는지 확인함.
  • 연락처·사유·목적지: 연락처는 숫자만 입력하면 형식이 자동으로 맞춰짐. 근무지를 벗어나는 복무는 목적지도 채움.
  • 이전 신청 재사용: 상신함에서 같은 복무 종류의 최근 완결 건을 열어 결재선·사유·연락처를 가져올 수 있음. 완결 건과 취소 건을 구분해야 함.

화면 처리에 시간이 걸려 에이전트가 같은 동작을 다시 하거나 잠시 멈춘 것처럼 보일 수 있음. 완료 응답이 나올 때까지 기다림.

5. 안전 경계

가. 세 가지 원칙

  • 자격증명: 인증서 비밀번호와 EVPN 비밀번호는 지시문이나 대화에 넣지 않음. 로그인은 본인이 직접 해야 함.
  • 확정 조작: 상신·접수·제출·발송처럼 되돌리기 어려운 조작은 본인이 결정해야 함. 에이전트에게는 확정 버튼 앞에서 입력값을 요약하고 멈추도록 지시함.
  • 화면 캡처: 성적·공문 등 민감한 화면은 이미지 파일로 저장하지 않음.

나. 자동화할 업무 고르기

에이전트에게 맡길 업무는 세 가지 기준으로 고름.

  • 반복되는가: 반복 업무는 절차를 정리해 두면 다음에도 그대로 쓸 수 있음.
  • 패턴이 있는가: 매번 같은 기준으로 처리하는 부분을 절차로 정리함. 판단이 필요한 부분에는 확인 단계를 둠.
  • 되돌릴 수 있는가: 되돌리기 어려운 일은 자동화하더라도 확정 앞에서 멈춤.
